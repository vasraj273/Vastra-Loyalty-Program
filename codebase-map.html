QR API — Complete Codebase Map

Project: Multi-tenant loyalty program backend for the VastraApp ecosystem.
Vastra (manufacturer app) generates QR codes for product stickers.
YourApp (retailer app) retailers scan codes to earn points and redeem gifts.
One FastAPI backend serves both.

Key Flow: What Happens When a Retailer Scans a QR

1
Retailer opens the printed QR with their phone → URL = https://yourhost.com/web/scan/TOKEN
2
app/web/scan.html loads → detects pathToken in URL → immediately calls redeem(TOKEN)
3
redeem() → POST /scan with { code: TOKEN } and the retailer's auth token in the header
4
In app/main.py, scan() function runs:
  • Looks up token in qr_codes table (joined with batch + product)
  • Checks redeemed_at IS NULL — if not null → "Code already redeemed" error
  • Checks retailer's manufacturer_id matches the code's manufacturer (cross-manufacturer scan rejected)
  • Finds the best active scheme for this product (highest bonus_points)
  • Calculates total = base_points + bonus_points
  • Sets redeemed_at = NOW on the qr_codes row
  • Writes a row to points_ledger with entry_type = 'scan'
5
Response sent back to scan.html → shows points earned card with product name, scheme bonus, new balance
6
If this is the retailer's first scan with location permission, captureLocationOnce() sends GPS coords to POST /retailer/location — pins the shop on the map forever
